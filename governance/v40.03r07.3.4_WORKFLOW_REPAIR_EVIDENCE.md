# v40.03r07.3.4 workflow-repair evidence

This AUTHORING revision addresses the six independent-review findings from
`v40.03r07.3.3` without changing the scientific payload or any PDF bytes.

## R0733-REV-001 — candidate-bound refresh receipt

`tools/run_authoring_revision.py` invokes `refresh_or_fallback()` before
`source.zip` or the candidate control plane is materialized. The invocation is
bound to the candidate version and an explicit ISO-8601 attempt timestamp.
`UPSTREAM_REFRESH_ATTEMPT.json` is mandatory and `not_yet_attempted` is no
longer an admitted candidate state.

## R0733-REV-002 — atomic four-dependency refresh

`tools/resolve_github_releases.py` resolves AF, AFC, GM, and AOD in an isolated
full-tree staging directory. The staged tree is semantically validated before
`governance/` and `stable/` are committed. Any failure discards the stage and
preserves the candidate tree; a fallback receipt records that no partial
candidate mutation was committed.

## R0733-REV-003 — complete fallback snapshot

A valid fallback contains exactly AF, AFC, GM, and AOD, is bound to the candidate
version, and is either a complete bootstrap snapshot or a complete prior
verified release lock. The AOD bootstrap descriptor binds the authorized stable
AOD bundle, payload manifest, PDFs, and source archive.

## R0733-REV-004 — executable REVIEW to GO

`tools/run_review_go_transition.py` validates a GO-recommended REVIEW bundle,
requires zero open/applied findings and an authority-bound decision, appends one
transition row, emits a deterministic GO successor, and opens Hydrogen r08 only
in the GO bundle.

## R0733-REV-005 — AF-accurate finding retirement

The review event model admits `VERIFIED_CLOSED`, `NOT_APPLICABLE_VERIFIED`, and
`WAIVED_BY_AUTHORITY` under explicit reviewer/authority rules. The superseded
immutable-lock finding can therefore be retired without falsely claiming that
its original action was performed.

## R0733-REV-006 — cross-bound phase state

Candidate status, release status, candidate version, review version, feedback
counts, upstream refresh state, transition state, GO eligibility, r08 state,
and the human-readable workflow state block are derived and cross-validated.
A stale or contradictory REVIEW/FEEDBACK/AUTHORING/GO representation fails.

## Validation scope

The release adds adversarial tests for missing refresh receipts, partial refresh
rollback, incomplete fallback sets, authority retirement, GO execution, and
phase/status drift. Main, Manual I, Manual II, and all scientific payload bytes
remain frozen.
