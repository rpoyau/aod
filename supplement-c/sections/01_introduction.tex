\section{Introduction}
This supplement records regime tests in the native AOD calculus and should be read together with the main AOD note and the AF protocol \cite{aod43_main_2026,af_protocol_2025}. Where familiar SI quantities are helpful, they are introduced in cited input blocks and attached only after the cited row has been fixed. Throughout the section blocks, NASA/JPL, NIST, SPARC, and the cited observational papers are used as render-layer anchors for input dictionaries and familiar comparison values.


\paragraph{Global float policy.} Exact/default-form rows and ratio statements are authoritative throughout this supplement. Floating-point values are attached only as render-layer conveniences after the cited row has been fixed. When a decimal or SI value is shown, it is a rounded display of the same cited row rather than the row itself.

\paragraph{Local extractor policy.} Any beat, cadence, or comparison extractor used in a section block is declared in that section and applied only after the cited row or cited ledger has been fixed. In particular, rendered comparison formulas and local quarter-cycle extractors are section-level modelling choices for readable worked presentation; they are not imported as external premises of the cited native row.
