\section{Introduction}
This supplement records native AOD regime tests in native units and native operator form and should be read together with the main AOD note and the AF protocol \cite{aod43_main_2026,af_protocol_2025}. Where converted witnesses are shown, they are attached after the cited native row. NASA/JPL, NIST, SPARC, and the cited observational papers are used as render-layer anchors for input dictionaries and familiar reference values.

\paragraph{Global float policy.} Exact/default-form rows and ratio statements are authoritative throughout this supplement. Floating-point values, when shown, are rounded render-layer displays of the same cited row rather than the row itself.

\paragraph{Local extractor policy.} Any beat, cadence, or comparison extractor used in a section block is declared in that section and applied only after the cited row or cited ledger has been fixed. Rendered comparison formulas and local quarter-cycle extractors are section-level modelling choices for readable worked presentation and do not enter as premises of the cited native row.
