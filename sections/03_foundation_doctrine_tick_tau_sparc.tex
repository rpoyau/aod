
\section{Foundation Doctrine: Ticks, Tau Cycle, and SPARC Fixture}

This foundation patch fixes the placement of the shared reporting doctrine.  Manual I/Main define the rule; Manual II applies the rule in compact worked D.E.C. examples.

\begin{itemize}
\item Temporal flow is duon-current cadence across relational distinction between anchored fields.
\item Measured time is relational tick count under a declared clock process. SADAR is a boundary-scoped returned-current, pressure, and attention-balance object. A declared clock process extracts ticks from a recurrence and compares them relationally.
\item \texttt{tau\_cycle} is the native phase-cycle coordinate.
\item \(\pi = \tau_{\rm cycle}/2\) is a declared display coordinate, not the native coordinate.
\item Frequency, SI seconds, wavelength, and energy are declared coordinate/report rows only when the active lane authorizes them.
\item SPARC is a 2D observable-data fixture under declared projection/readout policy. Derived diagnostic quantities, where declared, are outputs of that projection/readout rather than a classification of the dataset.
\end{itemize}

The exact native row is not replaced by its report coordinate.  The required sequence is
\[
\hbox{native exact row}\longrightarrow
\hbox{declared coordinate/report map}\longrightarrow
\hbox{conversion, projection, and error ledger}.
\]

Conversion error is not empirical residual.  Projection/report error is not a target agreement score.  Target joins, SI report values, metric report values, residuals, scores, empirical comparisons, subject/reference phase locks, native resonance periods, and hyperfine C6 pass/fail claims remain closed unless a later reviewed lane opens them explicitly.
