
\section{D.E.C. Report-Coordinate and Error-Budget Overlay}

Manual II uses the foundation doctrine from Manual I/Main. SADAR remains a boundary-scoped returned-current, pressure, and attention-balance object; a declared clock process supplies the tick extractor and relational comparison. Manual II does not introduce SPARC, tick measurement, or tau phase-cycle doctrine first.  Each worked D.E.C. example may attach a report coordinate only through the shared overlay ledgers.

The required worked-row pattern is
\[
\begin{array}{c}
\text{native D.E.C. packet}\\
\downarrow\\
\text{declared report coordinate}\\
\downarrow\\
\text{conversion operator}\\
\downarrow\\
\text{exact rational report row}\\
\downarrow\\
\text{error/enclosure ledger}\\
\downarrow\\
\text{closed-lane status}
\end{array}
\]

The shared source ledgers are:
\begin{itemize}
\item \texttt{manual-2/data/dec/dec\_conversion\_operator\_registry.csv}
\item \texttt{manual-2/data/dec/dec\_report\_coordinate\_overlay.csv}
\item \texttt{manual-2/data/dec/dec\_error\_budget\_policy.csv}
\end{itemize}

The overlay is not a target-join lane.  Conversion error is not empirical residual.  Projection/report error is not target agreement score.  Rounding error is not a metric report value.  Decimal display is not native exact value.

Circle rows keep \(\tau_{\rm cycle}\) native and attach \(\pi=\tau_{\rm cycle}/2\) only as a display coordinate.  Hydrogen Balmer rows keep tick-interval ratios native and attach frequency ratios only through an exact reciprocal-ratio operator.  Cs-133 rows expose an available reference-tick card while report activation remains closed until the lane authorizes it.  SPARC rows treat the database as a 2D observable-data fixture under declared projection/readout policy.
