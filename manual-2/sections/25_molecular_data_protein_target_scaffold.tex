\section{Molecular data and protein target scaffold}

The v40.02r02 scaffold remains the target-packet foundation, v40.02r03 adds the molecular chain-D.E.C. execution lane, and v40.02r04 adds the protein target-normalization gate before any AOD contact prediction or folding score. It leaves the elementary 118-element lane unchanged and extends the same application discipline upward:
\[
\text{Spec}\to\text{Raw D.E.C.}\to\text{Trace}\to\text{Detector/SADAR context}\to\text{target comparison}\to\delta_3\text{/residual audit}.
\]

\subsection{Molecular target packets}

The molecular-data lane declares component vectors, target-packet rows, route units, controls, and link-rule schemas. The canonical storage order for component vectors is explicit by column name:
\[
(n_C,n_H,n_N,n_O,n_P,n_S).
\]
The storage order is also recorded in \texttt{manual-2/data/molecular/molecular\_target\_manifest.json}. This avoids silent CHONPS/CHNOPS position errors.

The scaffold files are:

\subsection{Route units and link rules}

The first declared route unit is the water-equivalent shedding unit
\[
\mathbf w=n(H_2O)=(0,2,0,1,0,0)
\]
in the $C,H,N,O,P,S$ storage order. It is a formula-accounting route unit for future dehydration/condensation-style examples. It is not a kinetic mechanism, solvent model, or universal reaction law.

The methane row is a control:
\[
\mathbf c=n(CH_4)=(1,4,0,0,0,0).
\]
It is a carbon-saturation control and is not a default chain route. The link-rule registry records peptide and nucleotide-style water-route schemas as \texttt{schema\_declared\_deferred}; the chain detector is active for the v40.02r03 fixture rows while external target comparisons remain deferred.

\subsection{Milestone boundary}

This remains a scaffold/data-packet, internal chain-D.E.C., and target-normalization milestone. It does not release external chain scoring, molecular stability, reaction kinetics, solvent behavior, AOD contact prediction, protein folding prediction, 3D coordinate prediction, contact-map scoring, or biological-function inference. Those require later milestones with frozen predictions and target-comparison audits.
