\aodnoteblock{Plan printed before materialization}{This section materializes the first atlas layer for the native rest-cycle plan.  It records type cards and scope rows only.  It does not open a target join, residual, score, SI report, or empirical comparison.}

The atlas separates three layers:
\[
\text{native temporal flow}
\neq
\text{relational temporal measurement}
\neq
\text{metric report}.
\]
Duon current may flow before it is measured.  SADAR organizes that directed current on a boundary/window.  Temporal measurement is a later relational phase lock between a subject flow and a declared reference flow.

\subsection{Type discipline}

A bip is a directed transition token in a D.E.C. trace.  A trace count is a combinatorial count.  A cycle is a closure class.  RD is a path-conditioned reflection-duration accessor.  RCD is formed after RD.  Duonic pressure is a local coupling load.  SADAR is directed boundary-current flow.  None of these alone is a metric unit.

The native-flow row records the evolution and recurrence of SADAR current.  The measurement row is admitted only when a subject flow and a reference flow are locked by a declared phase relation.  A metric report is downstream of that measurement and requires a metrological reference card.

\[
\text{duon current flows}
\to
\SADAR\text{ flow is organized}
\to
\text{reference-flow lock measures it}
\to
\text{metric card renders it}.
\]
