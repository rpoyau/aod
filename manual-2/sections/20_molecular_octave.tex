\section{Molecular octave: formula fusion and residuals}

The molecular octave changes the observable dictionary from $Z$ to exact formula accounting. The procedure is still boundary setup, raw ledger, trace detection, frozen row, and observable map.

\subsection{Formula ledger}

For a component formula $F$, let $n_a(F)$ be the count of atom type $a$ in the CHONPS ledger. A molecular fusion row declares reactants $F_1,\ldots,F_k$ and a shedding vector $S_1,\ldots,S_m$. The output formula is
\[
F_{\mathrm{out}}=\sum_{i=1}^{k}F_i-\sum_{j=1}^{m}S_j.
\]
The residual against a target formula $F_*$ is
\[
\Delta_a=n_a(F_{\mathrm{out}})-n_a(F_*),
\qquad a\in\{C,H,O,N,P,S\}.
\]
A closed row has all six residual coordinates equal to zero.

\subsection{PubChem lane}

The PubChem file is a lookup map, not a premise. It records query keys and stable lookup URLs so a downstream acquisition step can bind the exact formula rows to external records without changing the rows themselves.


\subsection{Molecular chain-D.E.C. execution lane}

Release v40.02r03 activates the next molecular lane after the target-packet scaffold. The lane remains internal: it starts from declared chain words and committed component vectors, runs neutral raw D.E.C. rows, reads a trace, names detector/SADAR contexts, freezes formula rows, and records split/fission and $\delta_3$ audits. External target records are not premises of this run.

The central chain formula is
\[
\mathbf n(F_{1:n})=\sum_i \mathbf n(F_i)-\sum_{\ell=1}^{n-1}\mathbf r_\ell.
\]
For the committed water-route examples this specializes to
\[
\mathbf n(F_{1:n})=\sum_i \mathbf n(F_i)-(n-1)\mathbf n(H_2O).
\]
