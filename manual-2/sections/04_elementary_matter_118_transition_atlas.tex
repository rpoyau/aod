\subsection*{Closed-lane discipline}

The atlas deliberately keeps the following lanes closed:

\begin{itemize}
\item target values are not read;
\item SI frequency or metric report values are not attached;
\item residuals and scores are not computed;
\item subject/reference phase locks are not materialized;
\item hyperfine \(C_6\)-divisibility remains tested, not assumed.
\end{itemize}

The fail-closed audit rejects target insertion, SI-frequency promotion to native premise, premature metric-report materialization, and any claim that hyperfine \(C_6\) divisibility has passed before a native resonance packet exists.
