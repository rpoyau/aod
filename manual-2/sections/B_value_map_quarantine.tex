The value-map quarantine is recorded in
\begin{center}
\small\texttt{manual-2/data/protein/protein\_value\_map\_quarantine.csv}
\end{center}.
The active register remains deferred:
\[
\lambda_{\mathrm{molecule}},\lambda_{\mathrm{formula}},\lambda_{\mathrm{graph}},
\lambda_{\mathrm{chain}},\lambda_{\mathrm{fold}},\lambda_{\mathrm{bio}}
=\texttt{deferred\_not\_attached}.
\]

Manual II therefore does not release a folding value map, a coordinate-level AOD folding model, RMSD/TM-score/GDT scoring, a solvent model, a kinetics model, or a biological-function model.
