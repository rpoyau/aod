\section{Scoped PDB contact-map residual pilot}

This section executes the first PDB-scoped contact residual pilot with boundary, source, and metric guards. The score is not broad folding validation. It is one declared comparison row whose inputs were already frozen or declared in earlier gates.

\subsection{Input lock}

The pilot reads the declared scope files first:
\begin{center}
\small
\path{pdb_contact_comparison_scope_declaration.csv}
$\rightarrow$
\path{pdb_contact_comparison_leakage_checks.csv}
\end{center}
Only after those rows pass does the scorer read the frozen prediction packet and the target contact row:
\begin{center}
\small
\path{aod_contact_prediction_freeze.csv}
$\rightarrow$
\path{pdb_mmcif_contact_map_derived.csv}.
\end{center}
The input-lock rule is
\[
\text{scope rows first} \;\longrightarrow\; \widehat O_{ij}\text{ from freeze}\;\longrightarrow\; O_{ij}\text{ from target map}.
\]
Detection status. The frozen AOD packet is not read as a target row. It is the downstream record of
\begin{center}
\small
\begin{tabular}{c}
\texttt{ChainWordSpec + ReadOnlyTrace}\\
$\downarrow$\\
A$\Omega$D motif / curling-curls specification\\
$\downarrow$\\
SADAR context\\
$\downarrow$\\
frozen contact packet
\end{tabular}
\end{center}
For the GAS pilot this path is
\[
\texttt{trace\_mol\_005}\to\texttt{motif\_mol\_005}\to\texttt{sadar\_mol\_005}.
\]
Only after this freeze does the PDB/mmCIF target-contact row join downstream.
The PDBx/mmCIF atom-site table and distance matrix are not prediction premises; they are target-derivation ledgers already written before this pilot.

\subsection{Declared pilot row}

The declared scope admits exactly one evaluation pair for the committed GAS fixture:
\[
(i,j)=(1,3),
\qquad
\theta=8.0\,\text{\AA},
\qquad
|3-1|\ge 2.
\]
The frozen AOD packet gives
\[
\widehat O_{1,3}=1.
\]
Target-source status. The boundary/source/metric ledger records
\begin{center}
\small
\begin{tabular}{ll}
\texttt{target\_source\_type} & \texttt{manual\_pdbx\_mmcif\_fixture}\\
\texttt{contact\_definition} & \texttt{CA\_distance\_leq\_8.0A\_min\_sequence\_separation\_2}
\end{tabular}
\end{center}
This says that the row exercises the PDBx/mmCIF target-lane format by committed fixture payload; it is not an external PDB accession validation. The PDBx/mmCIF-derived contact row gives
\[
O_{1,3}=1
\]
from the previously derived target distance
\[
d_{1,3}=7.6\,\text{\AA}\le 8.0\,\text{\AA}.
\]
Therefore the scoped PDB residual is
\[
\Delta^{\mathbb Z}_{1,3}=\widehat O_{1,3}-O_{1,3}=1-1=0,
\qquad
\delta_{3,1,3}=0.
\]
