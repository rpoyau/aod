\subsection{Claim-level notes}
\label{man:rest-mass-claim-levels}

\paragraph{Question.}
How should the claim-level column be read in this manual?

\paragraph{Readout.}
The claim-level column separates a downstream comparison target from any stronger identity assertion.

\paragraph{Output Row.}
\begin{itemize}
  \item \textbf{mass comparison only}: the cited row supports a downstream comparison target but does not itself assert identity;
  \item \textbf{candidate identity}: reserved for later use if a row is explicitly promoted beyond comparison status;
  \item \textbf{full identity claim}: reserved for an even stronger downstream claim and not used in the present table.
\end{itemize}

\paragraph{Hook / Evidence.}
The manual remains downstream of the main note and does not use this section to introduce new theorem content or new identity premises.
