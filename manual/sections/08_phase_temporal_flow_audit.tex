\subsection{Falsification}\label{manual:phase-temporal:falsification}

\begin{itemize}[leftmargin=*]
\item a handed-relation-destroyed phase trace still forms semantic closure;
\item a shed object remains source-retained without explicit readmission;
\item a signature appears without trace origin, or signature identity is used to infer a unique source;
\item extractor counts change under complete reverse serialization;
\item an incompatible signature contributes a receiving-field tick;
\item passive tracing changes core state, or a report feeds task control;
\item cadence alone is recorded as coupling, or coupling alone defines a cadence;
\item anchor incidence \(d_H=1\) is recorded as intrinsic elapsed duration;
\item \(x_T\), \(N_C\), \(N_\kappa\), or \(d_H\) is substituted for another count type;
\item \(2d_\varphi\ge1\) changes a temporal count, closure witness, or geometry rather than kernel weighting only;
\item \(R_{C,A}\), \(\Delta\pi\), or \(\Delta\tau\) fails its exact integer/rational identity;
\item the downstream finite projection is promoted to native phase or temporal machinery.
\end{itemize}
