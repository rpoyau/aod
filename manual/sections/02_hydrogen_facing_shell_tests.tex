\section{Hydrogen-facing Shell Tests}\label{manual:hydrogen-shell-tests}

\subsection{Shared hydrogen-facing shell declaration}\label{manual:hydrogen:scope}
\aodnoteblock{Scope}{This section is a manual comparison section. It declares hydrogen-facing shell records, computes finite \(\SADARop_B\) values on a shell-cycle ladder first, and only then records wavelength/frequency/energy comparisons.}
\aodnoteblock{Data-support class}{Hydrogen shell tests instantiate D0 exact shell-ratio fixtures and O0 shell observable-map comparisons. Error quantities are shell-ratio or spectral-map residuals.}

The shared declaration is
\[
\mathbf a_H\vdash(F_H,R_H,\partial R_H,\omega_H),
\qquad
B_H=(\partial F_H,\omega_H).
\]
The shell family is indexed by an integer shell number
\[
S_n,
\qquad
n\in\mathbb Z_{\ge 1}.
\]
For the hydrogen-facing comparison records, the normalized shell-pressure ladder is declared by
\[
\widehat P^D_{S_n}:=-\frac{1}{n^2}.
\]
Thus a transition into shell \(S_m\) has normalized pressure difference
\[
\Delta \widehat P^D(n\to m)
=
\widehat P^D_{S_m}-\widehat P^D_{S_n}
=
\frac{1}{m^2}-\frac{1}{n^2}.
\]


\[
\boxed{\text{Hydrogen shell tests are finite }\SADARop_B\text{ values on a shell-cycle ladder.}}
\]
\aodnoteblock{Remark}{The normalized ladder is a manual comparison choice. The main-note pressure definition remains \(p^D=C_3\rho^D_\omega\).}

\aodnoteblock{Presentation policy}{The A\(\Omega\) ratios in the spectral tables are exact rational values. Decimal target ratios, wavelengths, frequencies, and percent errors are external presentation values. A \(z\)-score is recorded when the record carries an explicit uncertainty.}

\subsection{Shell-pressure table}\label{manual:hydrogen:pressure-table}
The Balmer comparison records use transitions into \(S_2\). The A\(\Omega\)-internal normalized pressure differences are
\[
\Delta \widehat P^D(n\to2)=\frac{1}{2^2}-\frac{1}{n^2}.
\]
The ratio to the \(3\to2\) record is
\[
\mathcal R_{n\to2}
=
\frac{\Delta \widehat P^D(n\to2)}{\Delta \widehat P^D(3\to2)}.
\]

\subsection{Hydrogen spectral-series extension}\label{manual:hydrogen:spectral-extension}
\aodnoteblock{Choice}{The Lyman and Paschen records use the same normalized shell-pressure ladder as the Balmer records. The destination shell \(S_m\) is declared before each transition table. Ratio comparison is performed before wavelength, frequency, or energy export.}

For a fixed destination shell \(S_m\) and a transition \(n\to m\), with \(n>m\), define the A\(\Omega\)-internal series ratio
\[
\mathcal R_{n\to m,\AO}
=
\frac{\Delta\widehat P^D(n\to m)}{\Delta\widehat P^D((m+1)\to m)}.
\]
For wavelength comparison, use the inverse-wavelength relation
\[
\mathcal R^{\lambda,\mathrm{tar}}_{n\to m}
=
\frac{\lambda_{(m+1)\to m}}{\lambda_{n\to m}}.
\]
Thus the A\(\Omega\)-internal pressure ratio is compared against the measured inverse-wavelength ratio. external frequency coordinate and energy export remain downstream.

\subsection{Error audit}\label{manual:hydrogen:error-audit}
For a transition record \(x\), record
\[
\Delta\mathcal R_x
=
\mathcal R_{x,\AO}-
\mathcal R_x^{\mathrm{tar}},
\qquad
\epsilon_x^{\mathrm{sgn}}
=
100\frac{\Delta\mathcal R_x}{\mathcal R_x^{\mathrm{tar}}}.
\]
The ratio table above uses this formula. Energy errors may be recorded only after the wavelength target and external conversion are declared.
