% Traceability: manual-local contract and reading guide for the downstream manual
\section{Introduction}

\subsection{Purpose}
Manual 43$^\circ$C is the downstream visible manual for the AOD note. It gathers worked rows, converted witnesses, regime witnesses, and companion artifacts without introducing a second theorem source.

\subsection{Reading contract}
Inline tables in Manual 43$^\circ$C are the authoritative visible rows; CSV files, notebook outputs, and figure artifacts are companion materials only.

The manual is downstream of the main note; cited rows are fixed first, and converted or comparison renderings are attached afterward where declared.

The manual introduces no new theorem source; any local rendering or comparison rule stated here is subordinate to the main note and does not redefine the core calculus.

\subsection{Document grammar}
The manual uses one public section grammar throughout:
\begin{itemize}
  \item Question
  \item Readout
  \item Operator Chain
  \item Output Row
  \item Temporal Conversion Block
  \item Converted Witness Table
  \item Figure Witness
  \item Hook / Evidence
\end{itemize}
Draft numbering from the supplement layer is suppressed in the public PDF. Traceability is preserved in source comments and in the source-only traceability map.

\subsection{Artifact policy}
Figures are kept local to the row or witness they serve unless a diagram is genuinely shared across multiple sections. Notebook paths, CSV assets, and figure assets are recorded in Appendix~A rather than in the running body of the manual.
