\section{Introduction}
\label{man:introduction}

This manual shows how to perform AOD simulations and predictions from declared field rows. Each worked example identifies a retained AO field, declares a working level and window, runs the AFC/AOD chain, fixes an exact row, and then maps that row into a named report or benchmark layer. Measurement-facing SI output uses the BIPM SI Brochure as the SI reference and NIST CODATA listings for numerical constants or conversion factors~\cite{bipm_si_brochure_2025,nist_constants_complete}.
