\subsection{Transport/current fields}
\label{man:transport-current-fields}

This worked example instantiates the integer boundary-path calculus from Appendix~\ref{app:integer-boundary-path-diagrams}.  The retained chain is
\[
D_e\to u_e^{(\mathrm{tr})}\to U_K\to \mathcal J_K\to w_\perp,
\]
with all displayed rows computed from the manual-local setup file and exact rational arithmetic.

The carrier-family partition is disjoint in the setup file:
\[
E_K(\omega)=E_{K,\mathrm{duon}}(\omega)\cup E_{K,\mathrm{tetron}}(\omega)\cup E_{K,\mathrm{other}}(\omega),
\qquad
E_{K,a}\cap E_{K,b}=\varnothing\quad(a\neq b).

\[
\mathcal J_{K,\mathrm{duon}}+\mathcal J_{K,\mathrm{tetron}}+\mathcal J_{K,\mathrm{other}}
=\mathcal J_K.
\]

\subsubsection{Transverse witness audit}
\label{man:wire-current-transverse-witness-audit}

The two-sided probe convention is
\[
\epsilon_{e,+}^{\perp}=+1,
\qquad
\epsilon_{e,-}^{\perp}=-1.
\]
Thus the exact transverse witness is
\[
w_\perp^+=\sum_e\chi_eu_e^{(\mathrm{tr})},
\qquad
w_\perp^-=-\sum_e\chi_eu_e^{(\mathrm{tr})}.
\]
The row values in Table~\ref{tab:wire-current-compact-report} give
\[
w_\perp^+=\frac{3151}{37800},
\qquad
w_\perp^-=-\frac{3151}{37800},
\qquad
w_\perp^+ + w_\perp^- = 0.
\]
The witness namespace remains
\[
\boxed{B^*\neq \mathcal J_K\neq w_\perp}.
\]

\subsubsection{Phase, chirality, and probe-side audits}
\label{man:wire-current-phase-chirality-audits}

The exact audit trace checks the following row identities:
\[
r_e=0\Rightarrow u_e^{(\mathrm{tr})}=0\Rightarrow w_\perp=0,
\]
\[
r_e\mapsto -r_e\Rightarrow \mathcal J_K\mapsto -\mathcal J_K,
\qquad
w_\perp\mapsto -w_\perp,
\]
\[
\chi_e\mapsto -\chi_e\Rightarrow w_\perp\mapsto -w_\perp,
\qquad
\epsilon_{e,+}^{\perp}=-\epsilon_{e,-}^{\perp}\Rightarrow w_\perp^+=-w_\perp^-.
\]
