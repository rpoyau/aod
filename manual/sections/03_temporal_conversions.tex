\section{Exact-to-report maps and temporal calibration}
\label{man:exact-to-report-maps}

Report quantities are attached only after an exact row has been fixed under the main note \cite{aod43_main_2026}. The AO field relation is generated by the exact row; SI-facing values are calibration or report targets governed by the SI reference convention and declared constant tables~\cite{bipm_si_brochure_2025,nist_constants_complete}.

The generic exact-to-report map has type
\[
\Psi_R:
\mathrm{ExactRow}_{\ell}(\mathcal F_K,\omega)
\longrightarrow
\mathrm{ReportQuantity}.
\]
Specific worked examples instantiate this type with maps such as \(\Phi_{\varpi}\), \(\Phi_{\mathrm{lens}}\), \(\Phi_z\), \(\Phi_{\mathrm{shell}}\), and \(\Phi_{\mathrm{SPARC}}\). A comparison row is not complete until its map is explicit. Dataset-facing maps such as \(\Phi_{\mathrm{SPARC}}\) also cite the source snapshot and its source units before the row is accepted~\cite{sparc_paper,sparc_site}.

\subsection{Level-relative units}
\label{man:level-relative-units}

Exact rows are recorded at a declared working level \(\ell\), using \(\mathrm{bip}_{\ell}\) for counts and \(\mathrm{biz}_{\ell}\) for reciprocal rates. When \(\ell=0\) is declared, the manual writes \(\mathrm{monon}_0\), \(\mathrm{bip}_0\), and \(\mathrm{biz}_0\). This is a declared report level for the row.

\subsection{Comparison discipline}
\label{man:comparison-discipline}

Every comparison table names its report map. If the report map has not yet been written, the calculated field is recorded as pending rather than complete.
