
\section{Foundation Doctrine: Tick Measurement, Tau Phase-Cycle, and SPARC}

Manual I carries the conceptual classification for the foundation release.  Manual II may reference this doctrine, but it does not establish the doctrine first.

\subsection{Temporal and coordinate rule}

Temporal flow is duon-current cadence across relational distinction between anchored fields. Measured time is relational tick count under a declared clock process. SADAR is a boundary-scoped returned-current, pressure, and attention-balance object. A clock process declares a tick extractor and relational comparison; a report coordinate is attached separately when authorized.

Frequency, SI seconds, wavelength, and energy are declared coordinate/report rows when authorized.  They are not native premises merely because a worked example displays them.

\subsection{Tau phase-cycle rule}

\texttt{tau\_cycle} is the native phase-cycle coordinate.  The display coordinate \(\pi\) is declared only through
\[
\pi = \frac{\tau_{\rm cycle}}{2}.
\]
Decimal \(\pi\) is display-only and must carry a rational enclosure or display policy when used in a report coordinate.

\subsection{SPARC fixture classification}

SPARC is a 2D observable-data fixture under declared projection/readout policy. Derived diagnostic quantities, where declared, are outputs of that projection/readout. The dataset classification remains the 2D observable-data fixture.

The Manual-II SPARC worked example must therefore name the native object, the 2D data fixture, the projection/readout policy, the observable coordinate, and the projection/error ledger.  Target joins, residuals, scores, and empirical comparisons remain closed until an explicit source snapshot and projection map are authorized.

\subsection{Shared exact-row to report-row protocol}

Every worked D.E.C. example that exposes a report coordinate must preserve the native row and then attach a declared report map:
\[
\hbox{native exact row}\rightarrow\hbox{declared coordinate/report map}\rightarrow\hbox{conversion/projection/error ledger}.
\]

Native rows remain exact.  Report coordinates and error budgets are explicit overlays.  Conversion error is not empirical residual, and projection/report error is not target agreement score.
