\section{Reproducibility format}
\label{app:manual-reproducibility-format}

Each worked example names its reproducibility path:
\begin{itemize}[leftmargin=*]
  \item raw field setup,
  \item authoritative script or module,
  \item derived exact CSV,
  \item derived report CSV,
  \item derived trace CSV when the viewer is animated,
  \item figure artifact,
  \item falsification hook.
\end{itemize}

The PDF chapter, script, and derived CSVs must be sufficient for review. Notebooks remain optional viewers.

For every external source snapshot, the reproducibility record also names the citation key, source units, access date or dataset version, raw-file path, checksum when available, source-to-AOD normalization map, and AOD-to-source/SI comparison map. This keeps the source layer, AOD exact row, simulation, and comparison rendering auditable as separate stages.
