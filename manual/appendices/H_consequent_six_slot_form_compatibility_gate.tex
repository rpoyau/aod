\subsection{Gate question}

The primitive packet
\[

\]
fixes the shared six-slot support/enclosure card used by this Manual-I lane.
This appendix asks a deliberately narrow question about the carried forms
\[
3{:}3{:}6=\text{Tritriohexon},
\qquad
3{:}4{:}6=\text{Tetratriohexon}.
\]
It verifies that both scoped occurrences use the frozen \(C_6\) enclosure,
satisfy the exact field-accessor laws, and bind every support-family artifact
to the same scoped occurrence.  It does not claim that the \(30\) or \(68\)
support members are local \(Q_4\) successor edges, and it does not yet
materialize an occurrence-specific local D.E.C. execution.

The accepted claim is therefore limited to
\begin{center}
\fbox{\parbox{0.88\linewidth}{\centering
same frozen \(C_6\) enclosure\\
+ exact field-accessor consistency\\
+ fully bound exact finite support-family measure.}}
\end{center}
No recurrence, temporal equivalence, SADAR cadence, metric-time calibration,
or monon-to-bip conversion is inferred.

\subsection{Support-family cardinality is not a local edge pool}

For a declared form \(p{:}q{:}L\), define the finite disjoint support family
\[
F_{p,q}=D_q^p\sqcup S_q,
\]
where \(D_q^p\) is the set of all length-\(p\) words over the declared
\(q\)-direction alphabet and \(S_q\) is a declared disjoint retained
support-shell set.  The support accessor is
\[
\Pi_\alpha=|F_{p,q}|=q^p+q.
\]
Thus
\[
3{:}3{:}6:\quad 27+3=30,
\qquad
3{:}4{:}6:\quad 64+4=68.
\]
The support-shell members are not local edges.  Their identifiers are
bookkeeping members of \(S_q\), separate from any later local Hamming-one
edge or event identifier.

The deterministic ledgers enumerate the complete Cartesian word set and the
complete retained support-shell set.  They place the uniform exact counting
measure
\[
\mu(u)=\frac{1}{|F_{p,q}|}
\]
on each member.  This measure is a declared analysis measure.  It is exact,
but it is definitional rather than an independently derived physical
probability law, and it is not the AFC/D.E.C. kernel at one local tesseract
vertex.  Its rows are non-temporal support-family rows, not causal events and
not bips.

A later local D.E.C. construction must separately declare a \(Q_4\) state,
source and target vertices, Hamming-distance-one edges, local admissibility,
an exact per-step kernel, and a connected event order.  Reusing the \(30\) or
\(68\) support members as local edge slots is forbidden.

\subsection{Frozen inverse-solver domain}

The diagnostic inverse equation is
\[

\]
Its domain is frozen before evaluation as
\[

\qquad
2\le q\le 4,
\]
where the upper bound records the declared \(Q_4\) directional-support basis.
The policy is hash-verified, semantically consumed, and pinned to this release
contract.  On that domain the source rows have the unique diagnostic solutions
\[

\qquad
\Pi_\alpha=68\Rightarrow(p,q)=(3,4).
\]
The scoped occurrence card remains the primary identity source; the inverse
solver is an audit and does not replace that declaration.

\qquad

\qquad

It then requires the occurrence card, support-family registry, measure

The evaluator recomputes the exact Cartesian word set \(D_q^p\), the complete

The mass-summary status is not trusted as an input conclusion; it must agree
with this recomputation.  The complete inverse solution set is also recomputed

Byte freeze and semantic binding are therefore separate checks, and both must
pass.

The gate also binds the scientific closure statuses, not only the numerical

\subsection{Counterfactual and fail-closed audit}

The source table, primitive support policy, occurrence cards, support-family
registry, measure contract, enumeration, analysis-mass audit, read-only support
packet, local-D.E.C. admission contract, accessor rows, and solver-domain rows
are hash-locked before compatibility evaluation.

Counterfactual packets are separately rehashed and passed through the same
evaluator.  Form-local controls include changing \(L\) to \(8\), incrementing
\(P^D\), incrementing \(Q^D\), swapping the two forms' mass packets, assigning
an unrelated mass-packet identity, deleting one enumeration member, and
mutating an inverse row's identity and \(\Pi_\alpha\).  Closed-semantics
controls attempt to open local D.E.C., target input, temporal inference,
recurrence labeling, read-only target access, or inverse identity replacement.
Global controls add a duplicate occurrence, duplicate measure packet, foreign
registry row, foreign enumeration row, unexpected inverse row, swapped form
blocks, stable cross-form interleaving, adjacent physical-row transposition,
and foreign measure/family identities on measure, read-only, and mass packets.
Every mutation must fail; the unchanged controls must pass.

The gate manifest is fail-closed.  It reports separate statuses for native
compatibility, counterfactual audit, cross-packet binding, enumeration
completeness, canonical identity, canonical enumeration mapping, global
packet-set closure, canonical physical serialization, pre-map identity closure,
closed-semantic binding, and inverse audit.  The overall gate passes only when
all statuses pass.  An unexpected counterfactual success makes the standalone
generator exit unsuccessfully.

\subsection{Admission boundary}

Each passing form is admitted only as a support/accessor input contract.  The
next valid construction order is
\[
\begin{gathered}

\to \text{connected local }Q_4\text{ D.E.C. execution},\\
\text{D.E.C. execution}
\to \text{returned-current detection}
\to RD/RCD
\to p^D,\\
\text{subject SADAR flow}
\bowtie \text{reference SADAR flow}

\end{gathered}
\]
At this gate the local D.E.C. trace, returned-current detector, RD distribution,
RCD packet, both SADAR flow packets, and primitive phase lock remain
unmaterialized.  Hydrogen admission remains blocked until its connected local
D.E.C. occurrence is built.  No observation target, SI report coordinate,
empirical residual, or score is read.
