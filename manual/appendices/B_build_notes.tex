\section{Build notes}

\subsection{Authority and build policy}
The root \texttt{refs.bib} file is authoritative for the document family; the manual copy is a managed mirror used for local compilation. The public release set consists of \texttt{main.pdf} and \texttt{manual.pdf}, with optional source and audit archives.

\subsection{Table source policy}
Visible manual tables are authoritative. Curated CSV files feed numeric report-side tables where declared; notebook outputs remain companion materials only.
