\paragraph{Manifest rule.} Each salient calculation step is represented either in the visible supplement or in a shipped notebook, with the cited row remaining authoritative in the visible text. The visible supplement carries the cited input block, declared reduction, compact calculation block, formal row, and rounded rendering. The notebooks carry executable code, figure generation, and any full-precision manifests that would be distracting in the visible section text. Each shipped notebook is intended to be runnable on its own local dictionary and should expose exact/default-form ratios alongside any rounded render-layer values. Notebook-generated figure artifacts are stored canonically once under the supplement-wide \path{figures/} tree; the PDF and the notebooks both point to that same artifact location.
