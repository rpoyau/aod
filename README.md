# Alpha↔Omega Dynamics

This repository is the canonical source tree for the AOD theorem note and companion manual in AFC/AF form.

## Public document family

- `main.tex` -> `main.pdf` - theorem/calculus source
- `manual/main.tex` -> `manual.pdf` - companion public manual

## Source tree

- `manual/` - companion manual source package, manual-local data, figures, notebooks, audits, and appendices
- `audit_pack/` - audit rows and verifier files retained for explicit checks
- `notebooks/` - main-note support notebooks
- `appendices/`, `sections/`, `consequences/`, `examples/` - theorem-note source material

The cited row remains the exact/default-form authority. Converted or comparison witnesses are attached afterward where declared.
